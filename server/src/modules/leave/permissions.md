# Leave Module — Permissions

| Permission | Purpose | Required Roles |
|-----------|---------|---------------|
| `leave:apply` | Submit leave request | SUPER_ADMIN, ADMIN, PRINCIPAL, TEACHER, PARENT, STAFF, COUNSELOR |
| `leave:approve` | Approve/reject leave requests | SUPER_ADMIN, ADMIN, PRINCIPAL, TEACHER* |
| `leave:view` | View leave requests | SUPER_ADMIN, ADMIN, PRINCIPAL, TEACHER*, PARENT, COUNSELOR |
