# Academic Module — Permissions

| Permission | Purpose | Required Roles |
|-----------|---------|---------------|
| `student:view` | View student list and details | SUPER_ADMIN, ADMIN, PRINCIPAL, TEACHER, PARENT, COUNSELOR |
| `student:manage` | Create/update/delete students, bulk import | SUPER_ADMIN, ADMIN |
| `subject:manage` | Create/update grades, sections, subjects, class assignments | SUPER_ADMIN, ADMIN |
